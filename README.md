# Solar4U Form App

## Overview

Solar4U is a C# application designed for sales representatives to calculate quotations and provide loan offers to prospective clients. The app retains data after closure and includes functionality to search orders by transaction ID or date.

## Features

- **Quotation Calculation**: Generate detailed price quotes based on user inputs.
- **Loan Offers**: Provide loan options with varying terms and interest rates.
- **Data Retention**: Save and retrieve order data even after the application is closed.
- **Order Search**: Search through orders using transaction ID or date.
- **Client Interaction**: Confirm order details and gather client information interactively.

## Installation

1. Clone the repository.
2. Open the solution in Visual Studio.
3. Build and run the application.

## Usage

- Use the form to input client and order details.
- Generate quotes and loan offers.
- Search for past transactions using the search functionality.
